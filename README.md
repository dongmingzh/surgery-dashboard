# 胸外科手术数据分析看板

> 一个专注于胸外科手术工作量与术式结构分析的单页可视化工具。上传 CSV 后即可在浏览器本地完成分组统计、术式识别、图表展示和人工归类修正。

## 项目特点

- **单文件运行**：核心功能集中在 `index.html`，无后端、无数据库。
- **CSV 本地解析**：上传的数据仅在当前浏览器内存中处理，项目本身不会把 CSV 发送到服务器。
- **多维度看板**：展示总手术量、医疗组数、袖式切除量、主要术式及多类图表。
- **灵活分组**：可读取 CSV 中的“医疗组”、“组别”或“医疗组别”列，也可在页面中修改。
- **自动归类 + 人工修正**：优先使用 CSV 中的分类，否则按手术名称自动识别，并允许逐条修正。
- **安全渲染**：CSV 文本使用 DOM 文本节点展示，避免将上传内容当作 HTML 执行。
- **响应式布局**：兼容桌面和移动端屏幕，图表会随窗口大小调整。

## 快速使用

### 方式一：直接打开

1. 下载仓库中的 `index.html`。
2. 双击文件，使用 Chrome、Edge 或 Safari 打开。
3. 页面默认显示已脱敏的合成演示数据。
4. 点击右上角“上传 CSV 数据”，选择本地数据文件。

> 页面使用 CDN 加载 Tailwind CSS、ECharts、PapaParse 和 Font Awesome，首次打开时需要联网。

### 方式二：启动本地服务器

如果浏览器对本地 HTML 有限制，可在项目目录中运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## CSV 格式说明

### 必需字段

| 字段 | 用途 | 示例 |
| --- | --- | --- |
| `手术名称` | 用于手术统计和自动分类 | `VATS右肺上叶袖式切除术+淋巴结清扫术` |

### 推荐字段

| 字段 | 用途 | 备注 |
| --- | --- | --- |
| `手术医生` | 医生维度统计 | 缺失时显示为“未知” |
| `医疗组` | 医疗组分组 | 也支持 `组别` 或 `医疗组别` |
| `手术分类` | 人工预先标注的分类 | 也支持 `分类` 或 `类别` |

### 最小可用示例

```csv
序号,医疗组,手术医生,手术名称,手术分类
1,一组,医生01,VATS右肺上叶袖式切除术+淋巴结清扫术,肺部
2,二组,医生02,VATS胸腹腔镜联合食管根治术,食管
```

### 导出 CSV 的建议

1. 在 Excel 中整理列名，避免重复列。
2. 选择“另存为”。
3. 文件格式选择 **CSV UTF-8（逗号分隔）**。
4. 上传前检查“手术名称”列是否存在。
5. 如果准备截图、分享或在公共场合展示，先完成数据脱敏。

## 页面使用教程

### 1. 导入数据

点击“上传 CSV 数据”并选择文件。文件名会显示在上传按钮下方。如果找不到“手术名称”列，页面会给出错误提示。

### 2. 检查医疗组

1. 点击“医疗组设置”展开面板。
2. 检查每位医生对应的组别。
3. 如需调整，输入新组别后点击“应用分组设置”。
4. KPI 和全部图表会立即重新计算。

### 3. 阅读图表

- **各组手术总量**：对比不同医疗组的工作量。
- **各组术式构成**：观察各组手术类别的结构差异。
- **医生个人手术类型分布**：按医生展示不同术式数量。
- **全科室手术类别占比**：展示总体手术结构。
- **肺部手术细分**：对袖式、常规、全肺、楔形和肺段切除进行统计。

### 4. 修正自动分类

在页面底部“数据识别与修正明细”表中，使用每行右侧的下拉框调整最终统计归类。修正后看板会立即更新，修正项以橙色状态标识。

> 人工修正仅保存在当前页面会话中；刷新页面或重新上传文件后会重置。

## 分类规则

分类优先级如下：

1. 页面中的人工修正。
2. CSV 中的 `手术分类`、`分类` 或 `类别`。
3. 根据“手术名称”的第一个主要术式进行关键词识别。

当前主要类别包括：

- 肺部手术
- 食管手术
- 纵隔手术
- 胸部切除
- 其他手术

肺部手术继续细分为：袖式切除、全肺切除、楔形切除、肺段切除和常规肺切除。

## 隐私与数据安全

仓库内置的演示数据全部为合成数据，使用“患者001”、“医生01”和“DEMO001”等明确的演示标识，不对应任何真实人员。

实际使用时请遵守所在机构的数据安全制度：

- 不要将真实医疗 CSV 提交到 GitHub。
- 尽量在上传前删除姓名、身份证号、手机号、住院号、病案号和精确地址。
- 如果需要个人维度统计，优先使用无法直接识别个人的编码。
- 公开分享截图前，再次检查图表标签、悬停提示和明细表。
- 本工具不会自动将上传数据持久化；刷新或关闭页面后，当前内存数据消失。

## 常见问题

### 上传后提示找不到“手术名称”列

请检查列名是否完全一致，并使用 CSV UTF-8 格式重新导出。

### 页面没有样式或图表

请检查网络连接。样式和图表库由 CDN 加载，如果 CDN 被阻断，页面会提示资源加载失败。

### 中文显示为乱码

请在 Excel 中将文件导出为 **CSV UTF-8（逗号分隔）**，不要使用旧式 ANSI/GBK CSV。

### 修正结果能否保存？

当前版本不会持久化人工修正。如需长期保存，建议先在原始 CSV 中补充“手术分类”列，然后重新上传。

## 开发说明

项目无构建步骤。修改 `index.html` 后重新加载浏览器即可验证。提交前建议至少检查：

1. 默认演示数据能否显示。
2. CSV 上传和错误提示是否正常。
3. 医疗组设置能否展开、修改和应用。
4. 人工归类修正是否会联动 KPI 和图表。
5. 页面在宽屏和窄屏下是否可用。
6. 代码和演示数据中是否不含真实姓名或医疗标识符。
